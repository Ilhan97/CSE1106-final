The program allows users to enter a class temperature reading and thus determine if the temperature i within the acceptable range of 68 to 75 degrees Fahrenheit.
It will display the status with warning light using an LED connected to a Raspberry PI if the temperature is out of range, which will be OFF if the temperature is normal. 
It will also calculate the average of temperatures over a time period.
It will save the temp readings and statuses to a file
It will also users to change the acceptable temperature range according to clients requirements.
